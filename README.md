## 📚 Study Phases & Curriculum

### Phase 1 — C Programming (19 Oct 2025 – 31 Dec 2025)
- **Directory**: `C/`
- **Topics**: Standard I/O, operators, conditionals, loops, number theory fundamentals, pattern printing, functions, recursion, 1D/2D arrays, searching, sorting, string manipulation, pointers, dynamic memory allocation (`malloc`, `calloc`, `realloc`, `free`), singly linked lists, array/linked-list stacks, and circular queues.
- **Language**: C (C99/C11 standard)

### Phase 2 — Python + DSA (02 Jan 2026 – 31 May 2026)
- **Directory**: `Python_DSA/`
- **January**: Python fundamentals, idiomatic data structures, comprehensions, OOP, and mathematical algorithms.
- **February**: Arrays, two-pointer techniques, sliding window patterns, prefix sums, Kadane's algorithm, binary search, and core sorting algorithms.
- **March**: Linear and non-linear data structures: stacks, queues, linked lists, binary trees, tree traversals, and binary search trees (BST).
- **April**: Heaps/priority queues, graph representations, BFS/DFS, cycle detection, topological sorting, shortest paths (Dijkstra, Bellman-Ford, Floyd-Warshall), and minimum spanning trees (Prim, Kruskal, DSU).
- **May**: Recursion, backtracking (N-Queens, Sudoku), dynamic programming (Knapsack, LCS, LIS, Coin Change, MCM), Trie, and greedy strategies.
- **Language**: Python 3

### Phase 3 — DSA + Python Practice (01 Jun 2026 – 31 Jul 2026)
- **Directory**: `DSA_Practice/`
- **Topics**: LeetCode and interview-style problems focusing on optimization, edge-case handling, and advanced data structure design (LRU Cache, LFU Cache, monotonic stacks, tree serialization, complex graph traversal, 2D dynamic programming).
- **Language**: Python 3

### Phase 4 — DAA + DSA (01 Aug 2026 – 21 Oct 2026)
- **Directory**: `DAA_DSA/`
- **August**: Divide and conquer (Strassen's multiplication, Karatsuba, Convex Hull), greedy algorithms (Huffman coding, Job sequencing), and graph theory.
- **September**: Advanced dynamic programming (Travelling Salesperson Problem bitmask DP, Optimal BST), branch and bound (15-Puzzle, 0/1 Knapsack), and string matching algorithms (KMP, Rabin-Karp, Boyer-Moore, Z-algorithm).
- **October**: Strongly connected components (Kosaraju, Tarjan), network flow (Ford-Fulkerson, Edmonds-Karp), bipartite matching (Hopcroft-Karp), and specialized advanced data structures (Segment Trees, Fenwick Trees).
- **Language**: C++ (C++17 standard)
